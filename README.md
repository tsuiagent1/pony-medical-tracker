# Pony 醫療病歷與每日照護追蹤系統 (Pony Medical & Care Tracker)

專為崔董愛貓 **Pony**（13歲 / 已結紮母貓）打造的即時病例管理、血液數值儀表板與每日照護補水追蹤系統。託管於 GitHub Pages，支援手機與電腦端即時瀏覽與紀錄。

---

## 🌟 系統核心功能

1. **基本病歷與回診檔案**：完整記錄就診日期、醫院、主治醫師、診斷方向與門診費用明細。
2. **血液檢驗數值視覺化看板**：視覺化呈現 IDEXX 血檢數據（SDMA、CREA、BUN、HCT、HGB、RBC），並針對脫水與血液濃縮提供警戒色彩提示。
3. **每日照護打卡追蹤器**：
   - **每日補水量即時進度條**：設定 200~240 ml 達標目標，細分主動灌水（嚴守每日 50~80ml 限額與單次 5~10ml 限制）與濕食自發飲水。
   - **用藥打卡**：早/晚 消炎止痛與尿道放鬆膠囊服藥狀態。
   - **排尿與症狀評估**：記錄排尿次數、尿量規模、尿液顏色（血尿監測）與擠尿用力狀況。
   - **體重與備註紀錄**：每日追蹤體重變動。
4. **24小時急診警訊紅線指引**：隨時提醒完全尿道阻塞指標（頻繁蹲砂盆無尿、嘔吐拒食、下腹膀胱膨脹硬塊尖叫），提供緊急就診判斷標準。
5. **本地儲存與備份機制**：採用瀏覽器 `localStorage` 保存每日打卡資料與新增病歷，支援一鍵 JSON 匯出備份與匯入還原。

## 🚀 部署與啟用 (GitHub Pages)

本專案透過 GitHub Pages 進行靜態網頁託管：
1. 進入 GitHub 儲存庫 `Settings` ➔ `Pages`。
2. 在 `Build and deployment` 的 Source 選擇 `Deploy from a branch`。
3. Branch 選擇 `main` / `/(root)` 並儲存。
4. 約 30 秒至 1 分鐘後即可透過 `https://tsuiagent1.github.io/pony-medical-tracker/` 瀏覽。
